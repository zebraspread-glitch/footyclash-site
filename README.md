# FootyClash starter project

## How to use
1. Download and unzip this folder.
2. Open the folder in VS Code.
3. Run `npm install`
4. Run `npm run dev`

## Important edits before launch
- Put your real AdSense publisher ID in `app/layout.tsx`
- Replace the placeholder contact email in `app/contact/page.tsx`
- Replace the starter Privacy Policy and Terms text with real final versions
- Add your real game logic into `/app/solo`, `/app/local`, `/app/ai`, and `/app/online`
